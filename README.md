# Fleet-Management-Dashboard

**Project Overview:**
The project aimed to improve fleet visibility, operational efficiency, and financial reporting by developing real-time dashboards and automating reporting processes. The solution enabled stakeholders to monitor vehicle availability, fleet utilization, operational performance, and financial metrics through interactive reports.

**Key Responsibilities:**

* Gathered business requirements and identified key performance indicators (KPIs) for fleet operations.
* Designed and developed interactive Power BI dashboards to provide real-time visibility into fleet availability, utilization, and performance.
* Analyzed operational and financial data to identify trends, anomalies, and improvement opportunities.
* Automated manual reporting processes, reducing effort and improving reporting accuracy.
* Investigated and resolved discrepancies in UAE tax declaration workflows, ensuring accurate financial reporting and compliance.
* Collaborated with business stakeholders to define reporting requirements and deliver actionable insights.

**Tools & Technologies Used:**

* Power BI (Dashboard development, data visualization, KPI reporting)
* Microsoft Excel (Data preparation, validation, analysis, and reconciliation)
* SQL (Data extraction and validation, if applicable)
* Power Query (Data transformation and cleansing)
* DAX (Calculated measures and KPIs)

**Business Impact:**

* Achieved 95% accuracy in fleet tracking and reporting.
* Improved visibility into fleet operations through real-time dashboards.
* Reduced manual reporting effort through automation.
* Enhanced operational decision-making using data-driven insights.
* Improved financial reporting accuracy by resolving UAE tax declaration discrepancies.
